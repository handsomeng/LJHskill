# LJHskill 三轴状态协议

本文件是仓库真源。独立 Skill 使用各自 `references/three-axis-protocol.md` 副本，副本由 `scripts/sync_three_axis_protocol.py` 确定性同步。

## 一、字段决策状态

字段决策状态回答：这条定位、卖点、人群、场景、成本或经营口径能否作为已定输入继续使用。

| 状态 | 含义 | 下游规则 |
|---|---|---|
| 已确认 | 用户、品牌方或有权确认的上游已经确认，且能指出确认来源 | 可以原样复用，不得静默改写 |
| 待确认 | 信息缺失、口径未对齐，或尚未得到有权人员确认 | 可以放进初稿并标缺口，不得当成定论 |
| 修改建议 | 工具认为已有字段需要调整，但尚未获确认 | 保留原字段，同时单列建议与理由；确认前不得替换原字段 |

## 二、证据状态

证据状态回答：支撑某条事实、数字或宣称的材料目前有多可靠。

| 状态 | 含义 | 使用规则 |
|---|---|---|
| 已核验 | 已检查来源、时间、适用对象和口径，能追溯到材料 | 只支持核验范围内的结论 |
| 待核验 | 已有材料或说法，但来源、时间、适用对象或口径尚未核清 | 明示待核验，不得升级为事实 |
| 无证据 | 当前没有支撑材料 | 只能作为缺口或假设，不能对外宣称 |
| 已过期 | 材料曾可用，但已超出适用时间或基础条件已变化 | 需要重新取证，不能沿用旧结论 |
| 不适用 | 该字段不需要证据，或本场景确实不适用 | 写清不适用原因 |

## 三、验证结果

验证结果回答：一个预先定义的业务假设经过真实测试后得到什么结果。

| 结果 | 含义 | 后续动作 |
|---|---|---|
| 验证通过 | 设计、样本、指标口径和停止条件已事先写清，结果达到本轮适配后的判定标准 | 可以进入下一阶段，但不承诺放大后必然成功 |
| 信号偏弱 | 出现正向信号，但样本、稳定性、对照或关键指标不足以支持通过 | 补样本、复验或调整变量 |
| 验证失败 | 在有效设计和足够数据下，结果未达到停止条件或明确否定假设 | 停止当前假设，记录失败边界后换方向 |
| 未验证 | 尚未进行真实测试，或数据不足以形成有效判定 | 维持假设状态，不得包装为通过 |

## 四、轴间关系

1. 三个轴互相独立。字段已确认，不代表证据已核验；证据已核验，也不代表市场验证通过。
2. `/ljh-xuanpin` 的「进入验证」是资源决策结论，验证结果仍是「未验证」。
3. `/ljh-koc` 只用四种统一验证结果，不使用 S 级、初步通过、不过等替代标签。
4. `/ljh-suanzhang` 的预估模式只形成假设区间。输入证据按实际状态标注，不能伪装成实算或验证通过。
5. `/ljh-jiazhi`、`/ljh-dingwei` 和 `/ljh-maidian` 分别记录价值候选、标准定位草案和卖点评审的字段及证据状态，不把评审结果写成市场验证结果。
6. `/ljh-duiqi`、`/ljh-brief`、`/ljh-shangxiang` 和 `/ljh-jiaoben` 只消费上游状态。缺失时补「待确认」「待核验」或「未验证」，不得自行升级。
7. `/ljh` 只路由和传递状态，不修改下游结论。

## 五、生产者与消费者契约

| Skill | 生产或消费规则 |
|---|---|
| `/ljh-xuanpin` | 生产五个闸门的字段决策状态和证据状态；结论只能是「进入验证」「补数后再判」「暂缓」；进入验证时验证结果仍为「未验证」 |
| `/ljh-jiazhi` | 生产价值候选及其字段决策状态、证据状态；不生产标准定位 |
| `/ljh-dingwei` | 生产标准定位、标准人群和心智句草案；确认前不能标「已确认」 |
| `/ljh-maidian` | 生产卖点独特性、表达成立性与证据缺口评审；评审通过不等于市场验证通过 |
| `/ljh-koc` | 生产统一验证结果和对应证据状态；自然种草缺可归因消耗与净成交时不计算 ROI |
| `/ljh-suanzhang` | 生产财务输入的字段决策状态和证据状态；明确区分预估模式与实算模式 |
| `/ljh-duiqi` | 消费三轴状态并原样回填；任何改写都标「修改建议」 |
| `/ljh-brief` | 消费三轴状态并整理合作交付；待确认内容不得变成主播确定话术 |
| `/ljh-shangxiang` | 消费定位、卖点、人群、证据和验证结果；页面化改写标「修改建议」，不使用旧验证等级 |
| `/ljh-jiaoben` | 消费标准字段和证据状态进行结构评审；不把结构通过写成卖点或市场验证通过 |
| `/ljh` | 按三轴状态决定前进、补证、复验或回退，传递时不得升级状态 |
