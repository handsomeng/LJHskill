# 品牌档案模板

陪跑模式（模式 C）建档时按这份模板问齐品基本盘和人群两块，再往下走。档案存在后按主入口的档案协议读写，不覆盖旧内容。

```markdown
# 品牌档案

## 品基本盘
品名：
客单：
毛利率：
品类：
阶段：

## 人群

## 卖点与验证状态

## 红线与合规注意

## 结论时间线（新条目插入最上方，日期用 YYYY-MM-DD）

## 待办
| 日期 | 待办 | 来自哪个工具 | 状态 |
|---|---|---|---|
| | | | 没做 / 在做 / 做完了 / 不做了 |

## 金句和画面库
| 内容（原话或画面描述） | 类型 | 出处 | 状态 | 依据 |
|---|---|---|---|---|
| | 开场 / 卖点 / 促单 / 画面 | 哪条视频、第几秒 | 没测过 / 在测 / 有效 / 没效果 | 哪次复盘判的 |
```

金句和画面库的状态只由用户确认后改，工具不自动改。写稿时有效的可以原句用，没测过的可以改写，没效果的不用。依据写清是哪次复盘、哪个数据判的。
