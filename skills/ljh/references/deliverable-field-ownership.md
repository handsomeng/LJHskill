# LJHskill 交付物字段所有权协议

本文件是仓库真源。实际消费者使用各自 `references/deliverable-field-ownership.md` 副本，副本由 `scripts/sync_field_ownership_protocol.py` 确定性同步。

## 一、协议目的

字段所有权回答三个问题：谁能形成标准字段，谁只能提出建议，问题应退回给谁确认。字段决策状态、证据状态和验证结果继续使用三轴状态协议。

标准字段至少包含：标准定位、标准人群和心智句。心智句是让团队和消费者记住“这个产品是谁、凭什么值得选”的一句话。

## 二、所有权表

| Skill | 拥有的交付物 | 可以做 | 不得做 |
|---|---|---|---|
| `/ljh-jiazhi` | 价值候选与证据缺口 | 生成五层价值候选，记录来源、字段决策状态和证据状态 | 产出或替换标准定位、标准人群、心智句 |
| `/ljh-dingwei` | 标准定位、标准人群、心智句 | 消费已确认的上游资料和价值候选，形成定位草案；用户或有权负责人确认后记录为标准字段 | 把候选价值当事实，把未确认草案交给下游当成已确认 |
| `/ljh-maidian` | 卖点或主张评审报告 | 评审独特性、表达成立性和证据缺口，给局部修改建议 | 做合规批准、检测真伪鉴定、资质有效性确认，或静默改写标准定位 |
| `/ljh-duiqi` | 消费者语言、场景和画面翻译 | 翻译已确认字段，保留原字段与三轴状态 | 重新推导标准定位、标准人群或卖点 |
| `/ljh-brief` | 主播合作 Brief | 整理已确认字段、合作机制、演示提示和风险 | 重新定义标准字段，恢复固定页数，或把待确认项写成主播确定话术 |
| `/ljh-shangxiang` | 商详页说服地图 | 编排已确认字段、证据与验证结果，提出页面化修改建议 | 把待核验材料升级成页面承诺，或重做标准定位和标准人群 |
| `/ljh-jiaoben` | 脚本结构评审报告 | 诊断结构断点、证据和画面缺口，给局部修改方向 | 自动生成整篇替代稿，改写标准字段，或无依据精确打分 |
| `/ljh` | 路由与状态传递 | 按所有权把问题送回正确 Skill，原样传递字段和状态 | 生产、评审、翻译或改写业务字段 |

## 三、标准字段形成规则

1. `/ljh-xuanpin` 结论为「进入验证」后，才进入价值与定位阶段。
2. `/ljh-jiazhi` 只产价值候选。用户未确认的候选标「待确认」；工具提出的候选标「修改建议」。证据另标对应证据状态。
3. `/ljh-dingwei` 消费价值候选时保留候选属性，不得把候选直接写成事实。
4. `/ljh-dingwei` 产出的定位草案在确认前标「待确认」或「修改建议」。用户或有权负责人明确确认后，才记录为标准定位、标准人群和心智句。
5. 下游只把「已确认」标准字段作为固定输入。待确认内容可以进入初稿，但必须保留状态和缺口。

## 四、下游发现问题时的处理

下游不能覆盖标准字段。发现问题时，同时输出：

| 项目 | 内容 |
|---|---|
| 原标准字段 | 原文、来源、当前状态 |
| 修改建议 | 建议的新写法或调整方向 |
| 理由 | 渠道适配、证据不足、表达冲突或结构断点 |
| 回退所有者 | 负责该字段的 Skill 或有权负责人 |
| 确认动作 | 谁确认、确认什么、确认前如何使用 |

确认前，修改建议不能替换标准字段，也不能传给更下游作为已确认输入。

## 五、常见回退路径

| 发现的问题 | 回退所有者 |
|---|---|
| 价值候选缺来源或证据 | `/ljh-jiazhi` |
| 标准定位、标准人群或心智句需要调整 | `/ljh-dingwei` |
| 卖点独特性、表达成立性或证据缺口 | `/ljh-maidian` |
| 消费者语言、场景或画面翻译不清 | `/ljh-duiqi` |
| 主播合作信息缺失或渠道表达不适配 | `/ljh-brief`，涉及标准字段时再退回对应所有者 |
| 商详页信息顺序或页面承接问题 | `/ljh-shangxiang`，涉及标准字段时再退回对应所有者 |
| 脚本结构、局部句子、证据或画面缺口 | `/ljh-jiaoben` 给评审意见，由创作者修改后再评审 |

## 六、证据与批准边界

1. 卖点评审通过，只代表本轮独特性和表达检验通过，不代表市场验证通过或合规批准。
2. 资质、检测来源、检测机构、授权和平台规则由品牌方、法务、检测机构或平台合规人员确认。
3. 页面、Brief 和脚本只能在证据核验范围内表达。画面演示不能替代检测、资质或市场验证。
4. 虚构故事、名人同款、贵族或古老配方等材料没有可追溯授权与来源时，证据状态标「无证据」，不得进入标准字段。
