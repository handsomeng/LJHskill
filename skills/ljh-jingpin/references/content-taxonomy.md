# LJHskill 内容标签

本文件是仓库真源。拆解类工具使用自己 `references/content-taxonomy.md` 副本，副本由 `scripts/sync_content_taxonomy.py` 同步。给抖音带货短视频打标签时，只从下面的选项里选，这样不同工具、不同批次的结果才能放在一起统计。

## 一、钩子类型（开头 3 秒靠什么留人，单选）

跨工具统计钩子一律用下面这 13 类。这里的钩子只管开头留人，跟买点的四类由头（故事、痛点、场景、情绪）是两层。促销可以当开头钩子（归「福利价格」），不算买点。

| 标签 | 怎么认 |
|---|---|
| 痛点直给 | 一开口就说用户的不舒服或麻烦 |
| 反常识 | 说一个和大家以为的相反的事 |
| 否定同类 | 先说别家或常见做法不行 |
| 悬念好奇 | 话说一半，让人想看下去 |
| 结果前置 | 先亮出效果或结果，再讲怎么来的 |
| 点名人群 | 直接喊出是给谁看的 |
| 颜值视觉 | 靠好看的画面、产品质感留人，口播不是重点 |
| 对比测评 | 一上来就摆两样东西比 |
| 场景代入 | 先拉进一个具体的生活时刻 |
| 福利价格 | 开头就讲优惠、赠品、价格 |
| 热点借势 | 借节日、热点话题、流行梗 |
| 提问互动 | 用一个问题开头，让人想回答 |
| 其他 | 以上都不像 |

用「其他」时，在括号里写一个两到四字的补充类，比如「其他（地域身份）」「其他（怀旧）」「其他（亲情）」「其他（节令）」。同一批里同一个补充类出现 3 次以上，在报告里单列一行统计，但标签本身仍记为「其他」，跨批统计时并入「其他」。

## 二、视频形式（单选）

口播讲解、剧情、测评对比、教程清单、开箱、沉浸式展示、日常 vlog、探厂溯源、直播切片、混剪、其他。

## 三、流量元素

流量元素管让人停下来、看下去，属于表达形式层，不替代买点。它和第一节的开头钩子分工不同：钩子只看开头 3 秒怎么开，元素看整条内容靠什么设计留人。

| 元素 | 怎么认 | 带货里怎么用 |
|---|---|---|
| 反向操作 | 先演一个大家常做的错误做法，再翻过来做对 | 开头先演「洗锅泡一夜」，再用自家锅演示冲一下就干净，把反常识接回产品效果 |
| 晒过程 | 把使用过程一步一步拍出来，每一步都有看得见的变化 | 对应课程里的「高光流程」：挑开盖、上手、出效果几个节点，让产品自己出证据 |
| 挑战 | 定一个目标和时限，拍过程里怎么完成 | 比如「这口锅连做 7 天早饭」「一个保温杯扛过一周通勤」，把每天的记录串成一条完整说服线 |
| 对比 | 摆两样东西同时比，或者前后比 | 用前用后、跟替代品比、跟更贵的比，让产品赢在一个具体指标上 |
| 悬念 | 先抛结果或问题，把答案留到后面 | 开头问「为什么这家的四件套洗十次还不起球」，答案落在面料和工艺那一步 |
| 怀旧 | 讲老字号、老配方、地方特产的真实来历 | 用真实来历做故事由头，再把产品接到这个来历上 |
| 荷尔蒙 | 靠心动、好看、约会、送对象这类吸引力留人 | 用画面和情绪把人留住，落点回到产品，比如约会前的准备、送对象的场景 |
| 头牌 | 借行业之最、名人同款、榜单第一抬注意力 | 用「东北人冬天的早饭标配」「同事都在囤」这类说法抬注意力；有出处的排名和背书还可以放七步的「信任」那一步；没有来源时附下面那句提醒 |

### 怎么标

每条视频标一个主元素，最多再标一个辅助元素。八个都不像时标「无明显元素」，不用硬凑。

### 四条结合规则

1. **元素要长在买点上。** 元素的高潮落在产品出证据的那一刻：晒过程的结果是产品效果，挑战的完成靠产品撑住，对比的赢家是产品，悬念的答案落在产品力。自检这么做：把产品从视频里拿掉，只看高潮还在不在。高潮还成立，说明元素和产品是两张皮，流量会来，转化不会跟来。
2. **先磨内核，再加元素。** 新品先把买点和证据立住，再用元素做裂变：同一个内核配三个不同元素出三版，看哪一版留人。
3. **一条一个主元素，最多再叠一个辅助元素。** 做测试时一次只换一个元素，换两个就看不出是哪一个在起作用。
4. **只用真的。** 怀旧讲的来历、挑战里的天数和结果、对比里的数字、头牌里的排名和同款，都要有用户资料撑着；资料里没有就写「待确认」。

### 两句轻提醒

这两个元素都可以用，用到时在交付里附上对应那一句，提醒到位就行。

- 荷尔蒙：「和产品要有关系，别擦边，擦边内容容易被限流。」
- 头牌：「最、第一这类说法要有出处，名人同款要有授权，没有来源就换成有出处的说法。」

## 四、促单手法（可多选）

价格锚点、限时限量、赠品福利、从众、零风险承诺、场景提醒、关注引导、没有明确促单。

有任何一种具体手法时，不再同时标「没有明确促单」。

## 五、场景和人群

- 场景：这条视频卖的使用场景，8 个字以内的短语，比如「办公室加餐」「熬夜后早餐」。
- 人群：目标人群，8 个字以内，比如「带娃上班族」「健身新手」。

场景和人群不设固定选项。同一批内统计前，先把意思相同的说法合并（比如「上班族早餐」和「打工人早饭」合成一个），合并规则写进报告的数据口径。

## 六、使用规矩

1. 每条视频的钩子、形式各只选一个，标签名照抄上表，不自造近义词。
2. 流量元素按第三节的主辅规矩标：一条一个主元素，最多再带一个辅助元素，都不像标「无明显元素」。
3. 拿不准时选最接近的一个，在备注里写「拿不准，也像 X」，统计时按主标签算。
4. 小红书图文笔记不用这套标签，用 `/ljh-xhs` 自己的因子。
5. 标签只描述内容是什么样，不代表效果好坏；效果看受控测试和实操信号（问链接、问价格、问怎么买、晒单、复购），销量只用于品牌内分组。
