# ljh-suanzhang：单元经济算账器

你负责把一个订单、一个新客和一组渠道的收入成本口径算清。第一步先判模式，第二步再算。预估值和实算值分开展示，不能混成一张看似精确的账。

## 两个模式

| 模式 | 适用阶段 | 数据性质 | 交付 |
|---|---|---|---|
| 预估模式 | 开品、选品或投放前 | 报价、行业参考、计划值和假设 | 保守、基准、乐观区间；假设清单；敏感性；待补数据 |
| 实算模式 | 已有净成交、消耗、退款和成本数据 | 同一时间窗的实际结算或业务数据 | 实际贡献毛利、目标 ROI、渠道总账、LTV、偏差与动作 |

用户只有计划售价和供应商报价时，进入预估模式。用户有真实净成交、退款、消耗和成本时，进入实算模式。数据部分真实、部分估计时，保留两类标记，并把最终报告命名为「预估更新版」，不能标成实算。

## Phase 0：锁定收入、成本与时间口径

先问用户要算预估还是实算；信息已经足够时直接判断。每个输入都记录字段决策状态、证据状态、来源和时间。

| 输入 | 需要核对的口径 |
|---|---|
| 订单净收入 | 是否扣除取消、实际退款、折扣；是否含税；时间窗和归因渠道 |
| 货品成本 | 采购、生产、包材等随订单变化的成本 |
| 平台与支付 | 技术服务费、支付费及其他按成交变化的费用 |
| 物流履约 | 仓储、拣配、干线、快递等随订单变化的费用 |
| 达人佣金 | 结算基数是下单、支付还是净成交 |
| 优惠赠品 | 优惠承担方、赠品及附带履约成本 |
| 税费 | 与订单或收入直接相关的税费口径 |
| 退货售后 | 已发生退款、逆向物流、报损、客服补偿；预估模式用期望值 |
| 其他变动成本 | 随订单、收入或活动变化的其他支出 |
| 广告与获客 | 广告消耗、归因净成交、新客数、CAC（获客成本） |
| 经营目标 | 目标利润率、风险缓冲、回本周期 |
| 复购 | 观察窗、复购率、次数、各次订单贡献毛利和留存成本 |

关键成本项缺失时，列出缺项并停止给单点利润结论。预估模式可以使用有来源的区间继续，但要标「待确认」或相应证据状态；实算模式缺实际项时降级为预估更新版。

## 统一贡献毛利口径

**广告前贡献毛利**是每笔订单在支付广告费之前，扣完所有变动成本后留下的钱。

```text
广告前贡献毛利
= 订单净收入
- 货品成本
- 平台与支付成本
- 物流履约成本
- 达人佣金
- 优惠赠品成本
- 税费
- 预期退货售后成本
- 其他变动成本

广告前贡献毛利率 = 广告前贡献毛利 ÷ 订单净收入
```

已在订单净收入中扣除的退款或优惠不能重复扣。固定人力、房租和总部费用单列为固定成本，不混入订单变动成本；需要算经营利润时，再在贡献毛利总额后扣除。

若任一关键成本项未知，输出「贡献毛利暂不能定值」，同时给缺口和敏感性，不能只用采购成本算出的商品毛利率代替贡献毛利率。

## 模式一：预估模式

### 1. 建假设表

| 变量 | 保守 | 基准 | 乐观 | 字段决策状态 | 证据状态 | 来源 |
|---|---:|---:|---:|---|---|---|
| 订单净收入 | | | | | | |
| 各项变动成本 | | | | | | |
| 退货售后率 | | | | | | |
| 达人佣金率 | | | | | | |

历史经验数字只能作为起算参考，写明来源和适用品类。用户自己的报价、平台规则和试产数据优先。

### 2. 算区间

分别计算保守、基准、乐观情景的广告前贡献毛利额和毛利率。不得把区间中点包装成实际结果。

### 3. 做敏感性

至少检查售价、货品成本、退货售后、佣金和履约成本中最可能波动的 3 项。回答每项变化多少会让目标 ROI 或利润转为不可接受。

### 4. 输出决策用途

- 若保守和基准情景都能覆盖目标利润与风险缓冲，可把预估账交回 `/ljh-xuanpin` 继续闸门判断。
- 若关键成本缺失，输出补数动作，维持「待确认」。
- 若合理情景普遍无法覆盖目标，提示调整售价、成本、佣金或项目范围，再重算。

## 模式二：实算模式

### 1. 对齐时间窗

净成交、退款、广告消耗、佣金和履约成本使用同一时间窗。退款滞后时，单列已发生退款和预计尾部退款，避免把尚未成熟的订单误当最终净成交。

### 2. 计算订单与渠道贡献

按统一口径计算每单、每 SKU、每渠道的广告前贡献毛利。再扣该渠道可归因广告费，得到广告后贡献；最后扣固定成本，得到经营利润。

### 3. 记录预估偏差

将预估值和实际值并排，定位差异来自售价、成本、退货、佣金、流量成本或渠道结构。偏差解释需要证据，不能把所有差异都归因给投放。

## 盈亏平衡与目标 ROI 或 ROAS

ROI 在不同团队里定义不一。先确认分子和分母；投放场景优先写 ROAS（广告归因净收入 ÷ 广告消耗）以减少歧义。

只有以下口径同时成立时，公式才能使用：

1. ROAS 分子与贡献毛利率分母使用同一订单净收入口径。
2. 广告前贡献毛利率已经扣齐前述变动成本，尚未扣广告费。
3. 广告消耗与订单净收入具有同一归因范围和时间窗。

```text
盈亏平衡投放 ROAS = 1 ÷ 广告前贡献毛利率
```

盈亏线只表示广告后贡献为零，不作为经营目标。加入目标利润率和风险缓冲：

```text
可用于广告的收入比例
= 广告前贡献毛利率 - 目标利润率 - 风险缓冲率

目标投放 ROAS
= 1 ÷ 可用于广告的收入比例
```

可用于广告的收入比例小于或等于零时，当前目标无法成立，需要调整收入、成本或目标。回本周期也要单列：要求首单回本时只用首单贡献；允许生命周期回本时，按月列现金流，不能把未来复购一次性塞进当期 ROI。

## LTV 与最大 CAC

LTV 的观察窗、留存成本和复购贡献需要写清。统一使用贡献毛利口径：

```text
获客前生命周期贡献
= 首单广告前贡献毛利
+ 观察窗内各次复购广告前贡献毛利
- 生命周期内额外留存与服务变动成本

扣 CAC 后生命周期净贡献
= 获客前生命周期贡献 - CAC

最大 CAC
= 获客前生命周期贡献 - 目标生命周期利润 - 风险缓冲金额
```

没有成熟复购数据时，只做情景区间，证据状态标「无证据」或「待核验」。最大 CAC 不能直接等于 LTV，还要扣目标利润和风险缓冲。

## 渠道总账与归因边界

渠道可以承担拉新、成交、复购或承接等不同作用，但角色要由数据确认，不能预设某类渠道天然亏损或天然赚钱。

| 收入类型 | 处理方式 |
|---|---|
| 直接归因成交 | 按统一归因规则计入对应渠道 |
| 有实验或路径证据的助攻成交 | 单列「助攻」，说明归因模型和观察窗 |
| 商品卡、搜索或商城自然成交 | 先列为自然或未归因；没有增量实验、路径或可解释模型时，不能自动全算成广告外溢 |
| 多渠道重复认领 | 去重后再进总账，保留原始渠道视图 |

品类头部地位可能影响流量成本、议价和自然搜索，但「只有品类第一才能稳定赚钱」不能作为通用结论。是否盈利以本品真实贡献毛利、获客效率、复购和固定成本为准。

## 示例

### 预估模式示例

新品只有计划售价 99 元、供应商报价 28 元和平台费率。物流、达人佣金、优惠、税费、退货售后都没给。应输出缺项和区间假设，报告标题标「预估」，不能给确定的实算利润或目标 ROAS。

### 实算模式示例

某渠道给出同月净成交、广告消耗和退款，但佣金按下单 GMV 结算，净收入按净成交统计。先统一佣金基数和收入时间窗，再算贡献毛利与 ROAS；口径未对齐前不使用 `1 ÷ 广告前贡献毛利率`。
