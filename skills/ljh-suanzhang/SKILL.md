# ljh-suanzhang：算账

一单到底赚多少、投流 ROAS 要到多少才不亏、一个新客最多能花多少钱拉。开卖前按计划值估区间，开卖后按真实数据算实账。

你负责把一个订单、一个新客和一组渠道的收入成本口径算清。第一步先判模式，第二步再算。预估值和实算值分开展示，不能混成一张看似精确的账。

## 两个模式

| 模式 | 适用阶段 | 数据性质 | 交付 |
|---|---|---|---|
| 预估模式 | 开品、选品或投放前 | 报价、行业参考、计划值和假设 | 保守、基准、乐观区间；假设清单；敏感性；待补数据 |
| 实算模式 | 已有净成交、消耗、退款和成本数据 | 同一时间窗的实际结算或业务数据 | 实际贡献毛利、目标 ROAS、渠道总账、LTV、偏差与动作 |

用户只有计划售价和供应商报价时，进入预估模式。用户有真实净成交、退款、消耗和成本时，进入实算模式。数据部分真实、部分估计时，保留两类标记，并把最终报告命名为「预估更新版」，不能标成实算。

**交互规则：每轮最多问 3 个问题。** 缺的输入超过 3 个时，先问最影响结论的那 3 个，其余列进补数清单，用户答完再问下一批。同一项不重复问，档案里已经有的不再问。

## 和别的工具怎么分

| 情况 | 用哪个 |
|---|---|
| 一个渠道或整个盘赚不赚、盈亏线、目标 ROAS、LTV、最大 CAC | 本工具 |
| 指标波动，要找第一个红灯 | `/ljh-zhibiao` |
| 千川消耗或成交突然掉了，要找第一动作 | `/ljh-qianchuan` |
| 每周素材复盘，决定复刻哪条 | `/ljh-qianchuan-fupan` |
| KOC 测试该不该按验证通过收口 | `/ljh-koc` |

本工具只核算经济结果，不定位流量问题，也不替投手写预算和出价。和别的工具对账时，收入、消耗、退款和归因窗口用同一时间窗；千川素材复盘和掉量诊断里的实付口径，与本工具的实付口径一致。

## Phase 0：锁定收入、成本与时间口径

开场这样说：

> 先告诉我：这个品开卖了没有？没开卖就按计划价和报价估一个区间；开卖了就把同一段时间的净成交、广告消耗、退款和各项成本发我，算实账。

数据在哪导：

| 要的数 | 去哪拿 |
|---|---|
| 净成交、退款、订单 | 抖店后台 → 订单和售后，按同一时间窗导出 |
| 广告消耗、归因成交 | 千川后台 → 数据 → 账户报表 |
| 达人佣金 | 达人合作后台的结算单 |
| 货品、物流、包材、税费 | 采购单、快递账单和财务台账 |

两条降级路径：

- 只有计划价和供应商报价：走预估模式，出保守、基准、乐观区间，标「待确认」。这条能判覆盖不覆盖目标利润，判不到实际赚亏。
- 只有消耗和 GMV、没有成本：只算投放 ROAS 和缺口清单，不给贡献毛利结论。这条能判投放效率，判不到利润。

先问用户要算预估还是实算；信息已经足够时直接判断。每个输入都记录字段决策状态、证据状态、来源和时间。

| 输入 | 需要核对的口径 |
|---|---|
| 订单净收入 | 是否扣除取消、实际退款、折扣；是否含税；平台补贴算不算进来；时间窗和归因渠道。和千川两个工具对账时用实付口径：（用户实际支付净成交金额 + 电商平台补贴净成交金额）÷ 广告消耗 |
| 货品成本 | 采购、生产、包材等随订单变化的成本 |
| 平台与支付 | 技术服务费、支付费及其他按成交变化的费用 |
| 物流履约 | 仓储、拣配、干线、快递等随订单变化的费用 |
| 达人佣金 | 结算基数是下单、支付还是净成交 |
| 优惠赠品 | 优惠承担方、赠品及附带履约成本 |
| 税费 | 与订单或收入直接相关的税费口径 |
| 退货售后 | 已发生退款、逆向物流、报损、客服补偿；预估模式用期望值 |
| 其他变动成本 | 随订单、收入或活动变化的其他支出 |
| 广告与获客 | 广告消耗、归因净成交、新客数、CAC（获客成本） |
| 经营目标 | 目标利润率、风险缓冲、回本周期 |
| 复购 | 观察窗、复购率、次数、各次订单贡献毛利和留存成本 |

关键成本项缺失时，列出缺项并停止给单点利润结论。预估模式可以使用有来源的区间继续，但要标「待确认」或相应证据状态；实算模式缺实际项时降级为预估更新版。

## 统一贡献毛利口径

**广告前贡献毛利**是每笔订单在支付广告费之前，扣完所有变动成本后留下的钱。

```text
广告前贡献毛利
= 订单净收入
- 货品成本
- 平台与支付成本
- 物流履约成本
- 达人佣金
- 优惠赠品成本
- 税费
- 预期退货售后成本
- 其他变动成本

广告前贡献毛利率 = 广告前贡献毛利 ÷ 订单净收入
```

校验：各项变动成本加广告前贡献毛利，要等于订单净收入，差 1 元以上说明有重复扣或漏扣。已在订单净收入中扣除的退款或优惠不能重复扣。固定人力、房租和总部费用单列为固定成本，不混入订单变动成本；需要算经营利润时，再在贡献毛利总额后扣除。

若任一关键成本项未知，输出「贡献毛利暂不能定值」，同时给缺口和敏感性，不能只用采购成本算出的商品毛利率代替贡献毛利率。

关键成本项缺一项，收入与成本的口径就没有对齐。这时除了写「贡献毛利暂不能定值」，还要写明「成本没扣齐，1 ÷ 广告前贡献毛利率这个盈亏线公式现在不能用」，等成本补齐、口径对齐后再算。只扣货品成本算出来的商品毛利率或贡献毛利率，都不能拿去套这个公式。

## 模式一：预估模式

### 1. 建假设表

| 变量 | 保守 | 基准 | 乐观 | 定没定 | 有没有证据 | 来源 |
|---|---:|---:|---:|---|---|---|
| 订单净收入 | | | | | | |
| 各项变动成本 | | | | | | |
| 退货售后率 | | | | | | |
| 达人佣金率 | | | | | | |

历史经验数字只能作为起算参考，写明来源和适用品类。用户自己的报价、平台规则和试产数据优先。

### 2. 算区间

分别计算保守、基准、乐观情景的广告前贡献毛利额和毛利率。不得把区间中点包装成实际结果。

### 3. 做敏感性

至少检查售价、货品成本、退货售后、佣金和履约成本中最可能波动的 3 项。回答每项变化多少会让目标 ROI 或利润转为不可接受。

### 4. 输出决策用途

- 若保守和基准情景都能覆盖目标利润与风险缓冲，可把预估账交回 `/ljh-xuanpin` 继续闸门判断。
- 若关键成本缺失，输出补数动作，维持「待确认」。
- 若合理情景普遍无法覆盖目标，提示调整售价、成本、佣金或项目范围，再重算。

## 模式二：实算模式

### 1. 对齐时间窗

净成交、退款、广告消耗、佣金和履约成本使用同一时间窗。报告里必须写一句：「收入、退款、广告消耗和各项成本都取 {开始日期} 至 {结束日期} 同一时间窗」。退款滞后时，单列已发生退款和预计尾部退款，说明最近 7 天（或平台退款窗口内）的订单还没走完退款周期，不能当最终净成交；尾部退款按区间列，标证据状态，不并进本期已发生退款，也不编一个确定的尾部退款率。

### 2. 计算订单与渠道贡献

按统一口径计算每单、每 SKU、每渠道的广告前贡献毛利。再扣该渠道可归因广告费，得到广告后贡献；最后扣固定成本，得到经营利润。

### 3. 记录预估偏差

将预估值和实际值并排，定位差异来自售价、成本、退货、佣金、流量成本或渠道结构。偏差解释需要证据，不能把所有差异都归因给投放。

## 盈亏平衡与目标 ROI 或 ROAS

ROI 在不同团队里定义不一。先确认分子和分母；投放场景优先写 ROAS（广告归因净收入 ÷ 广告消耗）以减少歧义。

只有以下口径同时成立时，公式才能使用：

1. ROAS 分子与贡献毛利率分母使用同一订单净收入口径。
2. 广告前贡献毛利率已经扣齐前述变动成本，尚未扣广告费。
3. 广告消耗与订单净收入具有同一归因范围和时间窗。

```text
盈亏平衡投放 ROAS = 1 ÷ 广告前贡献毛利率
```

这条线在不同工具里有三个叫法，说的是同一个数：本工具叫盈亏平衡投放 ROAS，`/ljh-qianchuan-fupan` 叫保本 ROI，`/ljh-qianchuan` 叫盈亏线。三个名字对账时先确认口径，不要当成三条不同的线。

盈亏线只表示广告后贡献为零，不作为经营目标。加入目标利润率和风险缓冲：

```text
可用于广告的收入比例
= 广告前贡献毛利率 - 目标利润率 - 风险缓冲率

目标投放 ROAS
= 1 ÷ 可用于广告的收入比例
```

可用于广告的收入比例小于或等于零时，当前目标无法成立，需要调整收入、成本或目标。回本周期也要单列：要求首单回本时只用首单贡献；允许生命周期回本时，按月列现金流，不能把未来复购一次性塞进当期 ROI。

## LTV 与最大 CAC

LTV 的观察窗、留存成本和复购贡献需要写清。统一使用贡献毛利口径：

```text
获客前生命周期贡献
= 首单广告前贡献毛利
+ 观察窗内各次复购广告前贡献毛利
- 生命周期内额外留存与服务变动成本

扣 CAC 后生命周期净贡献
= 获客前生命周期贡献 - CAC

最大 CAC
= 获客前生命周期贡献 - 目标生命周期利润 - 风险缓冲金额
```

没有成熟复购数据时，只做情景区间，证据状态标「无证据」或「待核验」。最大 CAC 不能直接等于 LTV，还要扣目标利润和风险缓冲。

## 渠道总账与归因边界

渠道可以承担拉新、成交、复购或承接等不同作用，但角色要由数据确认，不能预设某类渠道天然亏损或天然赚钱。

| 收入类型 | 处理方式 |
|---|---|
| 直接归因成交 | 按统一归因规则计入对应渠道 |
| 有实验或路径证据的助攻成交 | 单列「助攻」，说明归因模型和观察窗 |
| 商品卡、搜索或商城自然成交 | 先列为自然或未归因；没有增量实验、路径或可解释模型时，不能自动全算成广告外溢 |
| 多渠道重复认领 | 去重后再进总账，保留原始渠道视图 |

品类头部地位可能影响流量成本、议价和自然搜索，但「只有品类第一才能稳定赚钱」不能作为通用结论。是否盈利以本品真实贡献毛利、获客效率、复购和固定成本为准。

## 示例（示例数字）

### 预估模式示例：缺项时

新品只有计划售价 99 元、供应商报价 28 元和平台费率。物流、达人佣金、优惠、税费、退货售后都没给。应输出缺项和区间假设，报告标题标「预估」，不能给确定的实算利润或目标 ROAS。

### 预估模式示例：算到底（示例数字）

家清清洁喷雾，到手价 45.0 元，商品毛利率 55%。用户补齐了变动成本的计划值（基准情景）：

| 项目 | 每单金额（元） | 来源 |
|---|---:|---|
| 订单净收入 | 45.0 | 计划到手价，已扣优惠券 |
| 货品成本 | 20.2 | 供应商报价（55% 商品毛利对应） |
| 平台与支付 | 2.3 | 按 5% 费率 |
| 物流履约 | 4.0 | 快递报价 |
| 达人佣金 | 0.0 | 自营，没有达人 |
| 赠品 | 1.5 | 计划赠品成本 |
| 税费 | 0.0 | 示例按不含税口径 |
| 预期退货售后 | 1.6 | 按同类目 8% 退款率和逆向物流估 |
| 其他变动成本 | 0.4 | 包材和客服 |
| 广告前贡献毛利 | 15.0 | 45.0 减去以上各项 |

校验：20.2 + 2.3 + 4.0 + 0.0 + 1.5 + 0.0 + 1.6 + 0.4 + 15.0 = 45.0。

算下来：

- 广告前贡献毛利率 = 15.0 ÷ 45.0 ≈ 33.3%。商品毛利率 55% 扣完变动成本只剩 33% 左右，用 55% 算会严重高估。
- 盈亏平衡投放 ROAS = 1 ÷ 33.3% ≈ 3.0。用 1 ÷ 55% 算出来是 1.8，按 1.8 投会高估可投的钱。
- 目标利润率 8%、风险缓冲 5% 时，可用于广告的收入比例 = 33.3% − 8% − 5% = 20.3%，目标投放 ROAS = 1 ÷ 20.3% ≈ 4.9。
- 敏感性：退款率从 8% 升到 15%（退货售后成本约 3.0 元），贡献毛利率降到约 30.2%，目标 ROAS 升到约 5.8。

报告标题标「预估」，以上全部是计划值，证据状态为「待核验」。开卖后用实算模式重算。

### 实算模式示例（示例数字）

某渠道本月同一时间窗的数据：

| 项目 | 金额（元） | 来源 |
|---|---:|---|
| 订单净收入 | 120,000 | 抖店订单扣除退款和折扣 |
| 货品成本 | 48,000 | 采购单 |
| 平台与支付 | 6,000 | 按 5% 费率 |
| 物流履约 | 12,000 | 快递账单 |
| 达人佣金 | 9,600 | 按净成交 8% 结算 |
| 优惠赠品 | 3,000 | 活动台账，只含赠品，折扣已在净收入里扣过 |
| 税费 | 1,200 | 按收入 1% |
| 预期退货售后 | 4,800 | 逆向物流、报损、客服补偿 |
| 其他变动成本 | 1,400 | 包材和客服 |
| 广告前贡献毛利 | 34,000 | 收入减以上各项 |
| 广告消耗 | 20,000 | 千川账户报表 |
| 广告后贡献 | 14,000 | 贡献毛利减消耗 |

校验：48,000 + 6,000 + 12,000 + 9,600 + 3,000 + 1,200 + 4,800 + 1,400 + 34,000 = 120,000；34,000 − 20,000 = 14,000。

算下来的结果：

| 指标 | 算式 | 结果 |
|---|---|---:|
| 广告前贡献毛利率 | 34,000 ÷ 120,000 | 28.3% |
| 盈亏平衡投放 ROAS | 1 ÷ 28.3% | 3.53 |
| 可用于广告的收入比例 | 28.3% − 8% − 5% | 15.3% |
| 目标投放 ROAS | 1 ÷ 15.3% | 6.52 |
| 本月实际投放 ROAS | 120,000 ÷ 20,000 | 6.0 |

本月实际投放 ROAS 高于盈亏线，低于目标线；广告后贡献 14,000 元。

佣金基数要先对齐：这份示例按净成交结算，已扣退款；如果合同按下单 GMV 结算，佣金要按同口径重算，不能直接套这个数。

### LTV 与最大 CAC 示例（示例数字）

沿用上面的单品，观察窗 180 天，首单和两次复购都按广告前贡献毛利算：
