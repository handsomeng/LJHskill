## 用户的素材观察任务

当产品方案依赖视频、直播、搜索页、详情页或包装的具体表现时，AI 先给用户派一个小任务：查看 1 至 3 个指定竞品的真实素材，再回传观察卡。

用户要观察已有内容，不承担重新拍摄、剪辑和设计。可以只回传文字，也可以附链接、截图说明、时间戳或画面变化。没有回传前，AI 只能判断「需要观察」，不能写具体素材结论。

AI 派任务时要说明：

1. 看哪个国家、哪个平台的竞品。
2. 看哪一条素材或哪一组素材。
3. 只观察哪一个问题。
4. 用多长时间回传。
5. 回传后会写回方案文档的哪一节。

一次只让用户完成一张卡，不要让他同时拆五个竞品和所有平台。

## 素材观察卡

```text
竞品名称：
产品名称与链接：
销售国家与平台：
素材发布时间或当前可见时间：
素材类型：短视频 / 直播 / 搜索页 / 商品详情 / 包装 / 评论区

一、画面与动作
首帧或第一眼看到什么：
人物处于什么状态：
产品出现了什么状态：
具体做了什么动作：
动作前后发生了什么变化：
素材中最容易被记住的视觉、声音或触感线索：

二、用户与场景
它服务谁：
用户处于什么时刻：
用户要完成什么任务：
用户看完后理解的核心承诺：

三、使用负担
需要几步：
需要什么工具、时间或环境：
哪一步最容易失败、麻烦或产生不确定感：
用户需要额外学习什么：

四、判断边界
我确认看到的事实：
我推测的解释：
我还没有看清的地方：
这条素材是否有用户反馈或数据支持：
观察者与观察日期：
```

## AI 的拆解方式

收到观察卡后，AI 必须写回方案文档的「竞品素材与观察」章节，并按照下面五项提问：

| 项目 | 要回答的问题 |
|---|---|
| 已满足 | 竞品已经解决了哪个场景任务，用户为什么愿意接受它 |
| 使用负担 | 用户付出了什么步骤、时间、工具、理解成本或失败风险 |
| 准备借鉴 | 借鉴产品机制、使用动作、内容结构、视觉锤、价格还是销售路径 |
| 准备改良 | 改哪个变量，改动能提高哪项满足效率 |
| 准备放弃 | 哪些做法与当前国家、品牌、人群或成本条件不匹配 |

AI 需要把事实和推断分开。单个素材能说明内容如何表现，不能单独说明市场规模、复购或普遍用户偏好。

## 微创新判断器

每个微创新候选都填写：

```text
已有场景：
已有基础需求：
竞品满足方式：
竞品仍留下的使用负担：
本次只改变的关键变量：
用户会看到或感到什么变化：
内容表达会提高什么效率：
价格、成本、供应链或法规影响：
最小验证动作：
通过标准：
```

判断规则：

1. 场景必须已经有明确证据或可观察需求。
2. 改动尽量集中在一个关键变量。
3. 改动必须带来可感知、可演示或可验证的变化。
4. 方案必须写出使用负担和实现代价。
5. 必须有一个低成本验证动作。

只有换名称、换颜色、堆功能或复制表面表达时，标记为「差异化表达」，不能直接标记为「微创新成立」。
