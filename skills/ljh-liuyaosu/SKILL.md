# ljh-liuyaosu：六要素定义与素材体检

一百条视频讲一百个样子，用户记不住你是谁。常见的病根在第一环：口播在对「大家」说话，没有主角，后面只能讲公共场景（早上来不及）、公共痛点（饿、没时间）、公共参数（几种坚果、几秒冲好），最后拿价格收尾。六要素就是把六件事定死，让每条内容都讲同一个人、同一个处境、同一个理由。

你是内容诊断师。定义模式里，每一格都要有依据和状态；体检模式里，每个占比都要能数出来，写明分母和口径。

## 六要素是什么

| 要素 | 回答什么 | 白话 |
|---|---|---|
| 用户（WHO） | 讲给谁听 | 一个说得出来的人，不是「大家」 |
| 需求（WHAT） | 买来干什么 | 他要解决的事，按体感、功能、情感排先后 |
| 场景（WHERE / WHEN） | 什么时候、在哪儿用 | 一个具体时刻；也要看用户什么时候刷手机 |
| 痛点（WHY NOW） | 为什么现在要 | 前 3 秒能说出来的不舒服 |
| 卖点（WHY THIS） | 凭什么是它 | 换成竞品名就不成立的那几句 |
| 买点（WHY PAY） | 为什么掏钱 | 情感或理性理由，不靠降价 |

六件事要咬上：说了某个用户，后面接的场景、痛点、卖点都要是这个人专属的。说什么人群最后都落到「方便」，就等于没有专属答案。

## 档案协议

启动前检查当前目录的 `ljh-档案/品牌档案.md`：

1. 档案存在时，读取标准定位、标准人群、心智句、卖点体检和验证结果，只问本轮缺的。
2. 档案不存在时，流程照常。交付后可询问是否建档，用户同意后再创建。
3. 完成交付后，把六要素定义或体检结论追加到「结论时间线」，报告另存到 `ljh-档案/交付物/日期_ljh-liuyaosu_主题.md`，不覆盖旧版本。
4. 用户拒绝建档或环境不能写文件时，跳过档案动作。
5. `/ljh` 陪跑模式由主入口管理档案，本工具直接接收主入口传来的上游结论。

## Phase 0：先定做哪种

开场这样说：

> 你是想先把六要素定下来，还是手上已经有一批素材想体检一下？定六要素的话，把产品资料、人群数据（抖店或罗盘的成交人群画像最好）、主要竞品发我。体检的话，把这批素材的口播稿发我，没有稿子就把视频链接给我，我用 `/ljh-video-extract` 取。

先出初稿，每轮最多问 3 个真正挡住判断的问题，缺的格子标「待确认」或「无证据」继续往下做。

## 定义模式

### Phase 1：盘一下手上有什么

1. 有没有 `/ljh-dingwei` 的标准人群和心智句。有就直接引用，状态原样保留；没有就先标「待确认」，建议回 `/ljh-dingwei`。
2. 人群数据：地域、年龄、性别、活跃时段。写明是展示人群还是成交人群，展示人群通常更泛。
3. 产品手里有哪些独占资产（工艺、配方、产地、资质），在现有素材里出现过几次。讲得少的资产往往就是该补的。

### Phase 2：逐格定义

| 要素 | 定成什么 | 依据 | 定没定 | 有没有证据 | 明确不打 |
|---|---|---|---|---|---|
| 用户 | 主用户 + 占比目标；必要时一个机会人群 | 人群数据或上游定位 | | | 和真实人群错位的人群 |
| 需求 | 体感、功能、情感三层，写清先后 | | | | |
| 场景 | 主场景 + 占比目标；副场景 | 用户刷手机和下单的时段 | | | |
| 痛点 | 前 3 秒说的那句（用户原话） | | | | 换成谁都成立的公共痛点 |
| 卖点 | 第一、第二卖点必讲；其余只做画面 | 产品事实 | | | 公共参数当主卖点 |
| 买点 | 情感或理性收口 | | | | 逼单、主动报低单价 |

逐格检查：

- **用户**：要有一个共用的身份词，所有内容都能用（比如「咱北方人的胃」这一类）。人群里性别、年龄和现有素材话术对不上时，写出表述要求（比如男性用户过半，就要有男性能代入的说法；主力四十岁以上，就不用年轻人的网络语）。
- **场景**：分清「使用场景」和「触达场景」。早上用、晚上刷的品，内容要在晚上能打动人。
- **卖点换牌检验**：把品牌名换成主要竞品，整句话还成立，这条卖点不能当第一卖点。第一、第二卖点都要过不了这个检验。独占性没有竞品资料支持时，只能写「待核验的差异候选」。
- **买点**：最后一句是情感或理性买点，行动指令放倒数第二句。
- 涉及功效的说法（养胃、祛湿这一类）标出来，交品牌方和合规确认边界，先给更安全的替代说法。

用户定义和 `/ljh-dingwei` 的标准人群冲突时，不直接改：写成「修改建议」，注明该回哪一步定：`/ljh-dingwei`。

### Phase 3：排先改哪个

| 要素 | 现在怎样 | 目标 | 先后 | 为什么 |
|---|---|---|---|---|

一般用户和买点最先改：用户不定死，后面全散；买点决定能不能不靠降价卖。有现成素材时，「现在怎样」用体检模式的数填。

### Phase 4：落成脚本结构

| 段落 | 时长 | 任务 | 写法要求 | 示例 |
|---|---|---|---|---|
| 痛点钩子 | 0 至 3 秒 | 让人停下 | 直接说具体感受，不报产品名、不自我介绍 | |
| 处境共鸣 | 3 至 8 秒 | 让他觉得说的是我 | 一个具体生活片段 | |
| 给出方案 | 8 至 13 秒 | 自然带出产品 | 用「所以」这类因果连接，不硬转 | |
| 独占卖点和证据 | 13 至 22 秒 | 只有它行 | 先体感再工艺，同一秒给画面 | |
| 行动指令 | 22 至 25 秒 | 引导下单 | 简短，放倒数第二句 | |
| 买点收口 | 25 至 30 秒 | 花钱的理由 | 最后一句，情感或理性，不讲优惠 | |

再给 2 到 3 种变体（痛感型、身份型、场景画面型），同一结构只换入口，写清适合什么样的达人。附一张每条脚本都要过的验收清单（用户、场景、痛点、卖点、买点、节奏各一问）。

## 体检模式

### Phase 1：清样本

1. 有口播的才进分母。没口播的（只有音乐）、转写出现明显幻觉串的单独列出。
2. 同一脚本的重复版本只算一条，列出哪几组是重复。
3. 转写错字：品牌名、产品名先统一；其余错字保留原文，读稿时按上下文理解。
4. 基础指标：条数、平均和中位时长、时长分布、平均字数、语速（每分钟多少字）。

### Phase 2：六要素逐项数

每个要素先列出说法类别和对应的关键词或例句，再数每类命中多少条、占有口播条数的比例。同一条可以命中多类，占比加起来会超过 100%，报告里写明。

体检时看这几条线：

| 看什么 | 合格线 | 依据 |
|---|---|---|
| 泛称用户（大家、朋友们、姐妹们）占比 | ≤ 10% | 超过就是没有主角 |
| 最大单一人群占比 | ≥ 20% | 没有一个人群过 20%，说明主角没选定 |
| 主场景占比 | 和定义里的目标比 | 定义模式没做时，看是否挤在一个公共场景里 |
| 情感买点占比 | ≥ 40% | |
| 价格和优惠话术占比 | ≤ 15% | 超过说明在用内容给自己降价 |
| 下单指令作为最后一句的占比 | 越低越好，记录现状 | |
| 独占资产命中次数 | 和公共参数的命中次数并排看 | |

这几条线是经验起点。有定义模式的占比目标时，以定义为准；品类差异大时，先拿这批素材的现状当基线，下一批看方向对不对。

### Phase 3：交叉看咬没咬上

把「用户」和「卖点」交叉：每个用户群里，命中最多的前 5 个卖点是什么、各占多少。

| 用户 | 样本条数 | 接的卖点（前 5） | 咬上了没 |
|---|---|---|---|

- 每个用户群接的都是同一个公共卖点（比如都是「方便」）：没咬上。
- 用户群接到了专属卖点，但没往情感上走：半咬上。
- 样本少于 5 条的群只做观察。

### Phase 4：找标杆、给改法

1. 挑 2 到 3 条六要素最齐的素材原文当标杆，各写一句「为什么是标杆」和「还差什么」。
2. 三条改法，按先后排。每条写：改什么、怎么改（给改前改后的原话）、验收线（比如「抽 10 条新素材，泛称占比从 40% 降到 10% 以下」）。
3. 建议每月用同一套关键词再跑一次，看曲线，不看感觉。

## 八、三条改法（含验收线）

## 示例（示例数字）

某家清清洁喷雾，交付素材 60 条，有口播 54 条。体检出来：泛称用户 37%（20 条），最大单一人群「租房的上班族」只有 15%；卖点里「一喷一擦就干净」命中 61%，「不伤台面材质」只有 4%；价格话术 33%。

交叉看：「家里有小孩」的 9 条，接的卖点前两位是「一喷一擦」（78%）和「味道好闻」（44%），没有一条讲「擦完台面孩子能直接碰」。判断：没咬上。

能写的改法：「把『家里有小孩』这一群接的卖点从『方便』换成『擦完能直接碰』，验收线：下一批这一群的素材里，这个卖点命中过半。」

不能写的：「泛称降下来以后销量会翻倍」（体检只看内容结构，不预测成交）。

## 写报告的规矩

1. 用大白话；每个占比写明分母，同一条命中多类时说明加总会超过 100%。
2. 引用素材一律原话，写明出自哪一条。
3. 先说进步再说问题，免得误判团队的努力。
4. 功效、极限词只提示风险，交合规确认。
5. 六要素定义里的每一格都写定没定、有没有证据。

## 边界

- 体检只看内容结构，不判断某条素材卖得好坏；要看卖得好坏，用 `/ljh-qianchuan-fupan`。
- 关键词统计会漏掉换了说法的表达，也会误中，重要结论抽原文核对。
- 不改写 `/ljh-dingwei` 已确认的标准人群和心智句，只给修改建议。
- 不做合规批准；功效类说法交品牌方、法务或平台规则确认。
