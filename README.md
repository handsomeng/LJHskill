# LJHskill 电商增长工具箱

LJHskill（老家伙 skill）电商增长工具箱：全网首个免费开源的内容电商增长赋能 skill 合集，总共 24 个业务工具。你只需要告诉我你的业务困惑是什么，我会自动选择合适的工具帮你解决问题。

LJH 取自李解、瀚森，「老家伙」是 LJH 三个字母的谐音。

**最新版本 v1.2.1**。最近一次大更新新增了千川素材复盘、直播间周复盘、同行直播间录屏拆解、竞品全量拆解、六要素定义与素材体检 5 个工具，旧工具全部改成大白话。历次更新见 [CHANGELOG.md](CHANGELOG.md)。

## 我们是谁

我们是一家专注内容电商增长的咨询公司，做线下课、咨询、内训和陪跑。这套工具从我们约 20 万字的内容电商实操课里提炼出来：把诊断表、判断标准、SOP 和填空模板做成 AI 能直接跑的工具，课程正文不在本仓库。

当年马斯克为了加快可持续能源普及，开源了自己的专利。我们也想这么做：把方法免费开源，让更多中国电商企业用 AI 把生意做好，走向全球。欢迎拿去就用，也欢迎同行一起迭代。

## 三步上手

1. **安装**：打开终端，贴下面的命令。
2. **开个新会话，输入 `/ljh`，或者直接说「调用老家伙」**：这是总入口，它会先问你卡在哪。
3. **用一句话说你的困惑**：比如「这个品值不值得做」「视频跑量很猛，直播间没人下单」「千川这周哪些素材该加预算」，它会带你去对的工具。

### Claude Code

```bash
claude plugin marketplace add handsomeng/LJHskill
claude plugin install ljh@ljhskill
```

装这一个就得到全部工具。

### Codex 或其他 AI 编程工具

```bash
npx -y skills add handsomeng/LJHskill -g --all
```

也可以直接对你的 AI 说「安装 ljhskill」。

## 按岗位怎么用

- **老板、操盘手**：`/ljh-xuanpin` 判断品值不值得做，`/ljh-suanzhang` 算账，`/ljh-zhibiao` 看指标为什么变
- **编导**：`/ljh-liuyaosu` 定六要素，`/ljh-jiaoben` 评审脚本，`/ljh-yinzi` 拆爆款，`/ljh-jingpin` 拆竞品
- **投手**：`/ljh-qianchuan` 查掉量，`/ljh-qianchuan-fupan` 每周复盘素材
- **直播负责人**：`/ljh-zhibo-fupan` 每周复盘，`/ljh-zhibo-chaijie` 拆同行直播间
- **商务**：`/ljh-daren` 选达人，`/ljh-brief` 给主播准备资料
- **产品**：`/ljh-kaipin` 开品，`/ljh-jiazhi` 和 `/ljh-dingwei` 想清楚价值和定位

## 两个省事的功能

**品牌档案**：工具跑完会问你要不要建档。建了以后，产品、人群、卖点和每次的结论都记在当前目录的 `ljh-档案/品牌档案.md` 里，下一个工具先读档案，不再重复问你。不想要就说不用。

**陪跑**：对 `/ljh` 说「带我从头打这个品」，它会从开品或选品开始，一环一环带你走到算账，每一环结束都停下来问你要不要继续。

## 如何更新

工具会在用完后偶尔提醒你有新版本，只提醒，不会自动安装，也不会上传你的内容。不想被提醒，设置环境变量 `LJHSKILL_DISABLE_UPDATE_CHECK=1`。

### Claude Code

```bash
claude plugin marketplace update ljhskill
claude plugin update ljh@ljhskill
```

更新后重启 Claude Code 生效。

### Codex 或其他 AI 编程工具

```bash
npx -y skills add handsomeng/LJHskill -g --all
```

## 给同行：参与迭代

- 改完任何一个工具，先跑 `python3 scripts/validate.py`。
- `evals/` 里每个工具有一份行为用例；`python3 scripts/run_evals.py --skill <工具名>` 会真调用模型来测，会产生费用，建议只跑改过的那个。
- 工具之间怎么传递「定没定、有没有证据、验证过没」，规则在 [shared/](shared/) 里。
- 用这套工具跑出过真实结果（成了或翻车了都算），欢迎提 issue 或加微信告诉我们，真实案例会变成新的用例和判断标准。
